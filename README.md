# 途记 TravelPlan

旅游多点路线规划器。在线地址：https://tripplan.xliu2253.chatgpt.site

## 使用

1. 点击地图设置，填写高德 **Web 端（JS API）Key** 和安全密钥。未配置时是示意地图，不是真实道路或实时导航。
2. 输入搜索城市，或从自动提示中选择；清空输入表示全国。所有地点搜索和输入联想都限制在已确认的城市，并按行政区代码二次核验；外市或无法核实归属的结果不会展示。高德连接后从行政区服务加载完整城市列表，手动输入的城市也会先解析为唯一行政区代码，无法确认时会阻止搜索。
3. 添加地点，起点和终点均可留空。至少两个有效地点即可确认预览。填写且启用的起终点保持固定，其余端点自动安排。关闭智能排列时使用列表顺序。
4. 点击地图标记切换有效／停用；灰色节点不参与规划，但保留位置。列表中的编号和起终点旁的状态按钮也能切换。拖动只改变位置，不会切换有效状态。
5. 修改地点、有效状态或路线设置后，旧路线立即清除；仅点击“确认并预览路线”后才显示新路线。驾驶比较路况推荐、少收费、距离优先，重复路线合并，最多三种。

搜索城市不删除或限制已经加入行程的地点，也不限制手动选点／坐标导入。Apple 地图链接只支持含地点坐标的分享链接，不是 Apple 搜索服务；导入后请核对坐标和地图位置，不能把地图中心坐标当作店铺位置。

## 本地运行

需要 Node.js 22 或以上，无需安装运行依赖。

```sh
npm start
# http://127.0.0.1:4173
npm test
```

`dist/` 是直接部署的静态网站，没有构建步骤。`scripts/serve.js` 只服务该目录，测试和文档不会公开到站点。

## 代码结构

- `dist/app.js`：页面控制器、搜索选择和确认预览流程。
- `dist/js/state.js`：行程状态、旧数据迁移与浏览器保存。
- `dist/js/map-view.js`：高德／示意地图、拖动缩放和节点交互。
- `dist/js/place-search.js`：高德地点／联想／城市请求、归一化、严格城市筛选。
- `dist/js/routing-service.js`：高德驾车／步行／骑行服务适配，不自动绘制路线。
- `dist/js/route-engine.js`：不依赖界面的有效节点筛选、带可选端点的路径排序、方案去重。
- `tests/`：纯算法、搜索适配和带模拟地图服务的控制器测试。
- `.openai/hosting.json`：现有 Sites 项目标识及静态发布目录，不含密钥。

关键业务逻辑有注释；样式只做格式化整理，不添加注释。地图层通过回调连接控制器，避免循环依赖。

## 规划边界与测试范围

- 顺序优化使用有向路程时间矩阵。最多 11 个有效地点使用精确动态规划，超过 11 个使用近似算法，并在页面说明不保证全局最优。时间矩阵反映请求时的路况，不预测几小时后抵达时的交通。
- 多点比较会消耗较多高德配额（N 个地点最多 N×(N−1) 次两点比较），并发限制为 3。高德请求失败、额度不足、路线不通不会回退为伪造的真实路线。
- 行程改动会使未完成请求失效，迟到的结果不会恢复被清空的节点或预览。
- 自动化测试使用模拟服务，不证明某家真实店铺已被高德收录。实际商家搜索、城市列表和实时路线仍取决于你自己的 Key 权限、配额及高德数据。

## 密钥与网址迁移

Key、安全密钥和行程仅保存在当前网站域名的浏览器存储中，未写入此仓库。JS API 在浏览器运行，前端安全密钥不能视作服务器秘密；生产公开服务建议按高德官方指引配置安全代理并设置访问白名单。

更换网址后浏览器存储不会自动跨域迁移，因此新网址需要重新填写高德配置。若设置了白名单，请允许 `tripplan.xliu2253.chatgpt.site`（本地调试另行允许本地域名）。不要提交个人 Key、浏览器存储或真实私人行程到 GitHub。

参考：[高德 PlaceSearch](https://lbs.amap.com/api/maps-javascript-api/reference/search/placesearch)、[行政区查询](https://lbs.amap.com/api/javascript-api-v2/guide/services/district-search)。
